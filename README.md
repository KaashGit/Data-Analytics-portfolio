# Data Analytics Portfolio

Hands-on analytics projects in Excel, SQL, Power Query, Power BI, and DAX.

## Projects

### 1. Sales Analytics Dashboard — Excel
Excel dashboard for summarizing sales performance and communicating key trends.
- Tools: Excel and the analysis/dashboard features used in the final workbook.
- Focus: sales KPIs, performance summaries, and dashboard communication.
- [Project README](01-Sales-Analytics-Excel-Dashboard/README.md)

### 2. Customer Churn & Retention Analysis
Analyzed customer churn across contract, tenure, internet service, payment method, and monthly-charge segments.
- Tools: MySQL, Excel, Power Query, Power BI, DAX.
- Headline result: 26.54% churn across 7,043 customers.
- [Project README](02-Customer-Churn-Retention-Analysis/README.md)

### 3. Automated Sales Reporting System
Built a folder-based weekly reporting workflow with data validation, SQL views, DAX KPIs, and a Power BI dashboard.
- Tools: Excel Power Query, MySQL, Power BI, DAX.
- Headline result: validated 933 synthetic order lines across 12 weekly CSV files and successfully tested manual refresh with a new weekly file.
- [Project README](03-Automated-Sales-Reporting-System/README.md)
